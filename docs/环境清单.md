## 三、需要配置的环境变量

| 变量 | 必填 | 缺失后果 |
|---|---|---|
| `API_KEY` | ✅ | 退化为公开默认值 `dev-only-key-change-in-prod`，**任何人可调你的接口** |
| `ZHIPUAI_API_KEY` | ✅（或任一 LLM 密钥） | `call_llm` 一路降级到模板拼接，答不出自然语言 |
| `ZHIPUAI_MODEL` | 建议 | 默认 `glm-4-flash` |
| `FEISHU_APP_ID` / `FEISHU_APP_SECRET` | 可选 | 飞书机器人 webhook 不可用 |
| `API_KEY_IN_HTML` | 可选 | 默认 `true`：把 Key 注入 Portal HTML（同源部署用；注意任何人都能读到） |
| `CHROMA_PATH` | 可选 | 默认 `/mnt/chroma`（Dockerfile 已写死该 ENV） |
| `PORT` | 可选 | 默认 8080 |

**省 Token / 拒答开关（V5-M2，2026-09-19 起）**：

| 变量 | 默认 | 说明 |
|---|---|---|
| `CACHE_SIM_THRESHOLD` | `0.92` | L1 语义近似命中阈值（问句余弦），<0.5 视为关闭 L1 |
| `REJECT_THRESHOLD` | `0`（关） | L2 拒答**硬短路**：top1 低于它直接拒，不调 LLM。开前必须用线上数据标定 |
| `SOFT_REFUSE_THRESHOLD` | `0.45`（已开） | 软拒答注入：top1 低于它时向 prompt 注入强拒答指令，LLM 仍可答真相关内容。**0.45 由云端 bge-m3 实测标定**（KB内最低 0.4972 / KB外最高 0.4397）|
| `CACHE_MAX_VECS` / `CACHE_MAX_DIM` | `300` / `2048` | L1 问句向量容量与维度上限 |

> ⚠️ **换 Embedding 后端必须重新标定以上阈值**（tfidf 与 bge-m3 的相似度基线完全不同）。
> ⚠️ **改阈值后必须 `DELETE /cache` 清快照**——缓存会把旧配置下的答案直接返回，新逻辑不生效（2026-09-19 实测踩坑）。

> ⚠️ **不要**把密钥写进 `cloudbaserc.json` —— 该文件已入 git，写了等于泄密。
> ⚠️ `.env` 被 `.dockerignore` 排除，**不会进容器**；线上必须走控制台配置。
