## 一、D2 密钥轮换步骤

> 原则：先在源头（智谱/飞书/你自定义）重置，再同步到线上环境变量 + 本地 `.env`。**先拿到新值再删旧值**，避免服务断档。

| # | 密钥 | 在哪重置 | 操作 |
|---|---|---|---|
| 1 | `ZHIPUAI_API_KEY` | 智谱开放平台 `open.bigmodel.cn` → API Keys | 新建密钥 → 复制新值；旧 key 确认新 key 可用后再删除 |
| 2 | `FEISHU_APP_SECRET` | 飞书开放平台 → 应用 `cli_aab2169e42badbea` → 凭证与基础信息 → 重置 App Secret | 重置 → 复制新值 |
| 3 | `API_KEY` | 自定义服务密钥（无第三方控制台） | 自行拟定新值（如 `lily-prod-key-<日期>`），更新到线上与本地 |

**同步落点（两者都要改）**：

1. **线上**：CloudBase 控制台 → 云托管 → `ltc-rag-bot` → 环境变量 → 改 `API_KEY` / `ZHIPUAI_API_KEY` / `FEISHU_APP_SECRET` 为新值
2. **本地**：`code/.env` → 同步三处新值（已 gitignore，不入库）

> 轮换后验证：线上 `curl -s <服务URL>/health` 仍返回 `api_key_mode=生产模式`；`/query` 仍真调 LLM 出自然语言（非模板拼接）。
