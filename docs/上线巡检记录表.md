## 六、常见异常 → 快查

| 现象 | 最可能根因 | 先查这 3 件事 |
|---|---|---|
| `/kb` 返 401 | 控制台 `API_KEY` 与本地不一致 | ① 控制台环境变量值 ② 请求头名是 `X-API-Key` ③ 是否把 `.env` 当成了线上配置（`.env` 被 `.dockerignore` 排除） |
| 回答是模板拼接、没有自然语言 | LLM 密钥缺失 | ① `ZHIPUAI_API_KEY` ② `ZHIPUAI_MODEL` ③ `/query` 返回里 `llm_used` 是否为 `false` |
| 知识库条数变 0 | COS 没挂载，容器重启后数据丢失 | ① 控制台 COS 挂载路径是不是 `/mnt/chroma` ② 启动日志实际 store path ③ 是否需要从归档恢复（见 `docs/归档运维SOP与静态资产清单.md`） |
| Portal 全站 401 | Portal 注入的 Key 与服务端不一致 | ① `API_KEY_IN_HTML` 是否为 `true` ② Portal HTML 里 `{{AUTO_API_KEY}}` 是否被真的替换 ③ 浏览器缓存旧 HTML |
| 服务反复重启 | 128 MB 内存 OOM | ① 日志搜 `Killed` ② 是否引入了重依赖（sentence-transformers 等）③ 回退到 `handoff-20260918` 基线对比 |
