### `/cache/stats` 实测样例（2026-09-18）

```json
{"total_snapshots":3,"hot_count":0,"max_entries":1000,"stale_count":2}
```

| 字段 | 含义 |
|---|---|
| `total_snapshots` | 快照总数（上限 `MAX_ENTRIES=1000`） |
| `hot_count` | `hit_count ≥ PROMOTE_THRESHOLD(2)` 的条数，即真正会被返回的缓存条数 |
| `max_entries` | 上限 1000 |
| `stale_count` | **因 KB 内容指纹变化已失效的快照数**（2026-09-18 新增，用于观测） |
