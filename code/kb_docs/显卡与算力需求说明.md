# 显卡与算力需求说明

本系统（LTC RAG Bot）**不需要显卡（GPU）即可运行**。所有重算力环节均通过云端 API 完成，本机只承担轻量的检索与调度任务。

## 一、本系统的算力架构

| 环节 | 实现方式 | 是否需要本地 GPU |
|---|---|---|
| LLM 推理（生成回答） | 智谱 glm-4-flash，API 调用 | 否 |
| Embedding（问句/文档向量化） | SiliconFlow BAAI/bge-m3（1024 维），API 调用 | 否 |
| 向量检索 | 自研 SimpleVectorStore：TF-IDF + BM25 + RRF 融合 + cosine 重排，纯 CPU | 否 |
| 服务承载 | CloudBase 云托管容器（1 核 CPU / 2GB 内存，COS 持久化） | 否 |

## 二、为什么不需要 GPU

1. **推理外置**：大语言模型不在本机运行，回答由智谱 glm-4-flash 通过 API 生成，算力消耗在模型服务商侧。
2. **向量化外置**：文档切片与问句的 embedding 均调用 SiliconFlow API，本机只存向量结果（vectors.npy）。
3. **检索是 CPU 任务**：数百条切片规模的混合检索（向量 + BM25 + 重排）是轻量计算，1 核 CPU 足够，毫秒级返回。

## 三、什么时候才需要 GPU

只有在**私有化部署开源模型**（例如用 Ollama 或 vLLM 自建推理服务、不走第三方 API）时才需要 GPU：

- 7B 参数级别的开源模型：通常需要 8GB 以上显存；
- 更大参数量的模型：显存需求随参数量近似线性增长；
- 量化（如 4-bit）可显著降低显存占用，但会损失部分精度。

本系统当前采用 API 方案，无此需求。如未来客户要求数据不出内网的私有化交付，按 FDE 交付流程另行评估硬件选型与成本。

## 四、常见问题

**问：没有显卡能不能跑大模型？**
答：本系统可以。推理和向量化都走云端 API，本机（包括 CloudBase 云托管容器）不需要任何 GPU。

**问：把这套系统搬到客户内网，需要什么硬件？**
答：若沿用 API 方案（内网服务器可出网调 API），普通 CPU 服务器即可；若要求模型也内网自建，才需按上节评估 GPU。
