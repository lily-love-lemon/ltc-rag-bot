# PRD：LTC 销售话术与招投标 RAG 问答机器人

**文档版本**：v1.0 · 2026-09-16
**交付方**：FDE 前沿部署工程师
**状态**：已完成 MVP 设计 · 可 2 小时内落地

---

## 1. 产品定位

为企业销售团队打造的 AI 超级大脑 —— 把公司产品白皮书、竞品对比、合同范本、中标案例做成可即时问答的向量库。销售在飞书群 @机器人，立即得到 FABE 格式的专业话术。

**一句话**：让每个销售开口都是产品专家。

---

## 2. 核心场景（MVP 只做这 2 个）

| # | 场景 | 用户输入 | 机器人输出 | 业务价值 |
|---|------|----------|-----------|----------|
| A | **销售现场问答** | 「客户问零下30度怎么保证续航」 | FABE 话术：Feature（电池规格）→ Advantage（三重保温）→ Benefit（-40°C 正常工作）→ Evidence（2024 冬奥会案例） | 新人也能像资深销售一样回答专业问题 |
| B | **招标文件上传生成初稿** | 上传招标文件 PDF | 7 章结构化技术响应初稿（项目理解、技术架构、实施方案、服务承诺、资质、团队、报价框架） | 4 小时 → 30 分钟 |

**后续扩展（MVP 之后）**：招投标智能检索、竞品对比问答、合同风险扫描、CRM 跟进自动同步。

---

## 3. 非功能需求

| 指标 | 目标 | 说明 |
|------|------|------|
| RAG 检索命中率 | ≥ 80% | 同一问题 5 次查询至少 4 次返回正确片段 |
| 首次响应时延 | ≤ 3 秒 | 从 @机器人 到飞书收到回复的端到端时间 |
| 支持并发 | ≥ 20 QPS | MVP 单机部署 |
| 向量库可更新 | ✅ | 上传新文档自动增量索引 |
| 本地化部署 | ✅ | 全部数据在企业内网，不上云 |

---

## 4. 用户角色

| 角色 | 使用方式 | 频率 |
|------|----------|------|
| 一线销售 | 飞书群 @机器人 提问 | 每天 5–20 次 |
| 售前/方案 | 上传招标文件生成初稿 | 每周 2–5 次 |
| 销售主管 | 管理知识库（上传/更新文档） | 每周 1 次 |
| 管理员 | 配置机器人、查看日志 | 每月 1 次 |

---

## 5. 功能清单（MVP 范围红线）

**✅ 本期要做**：
- F1：飞书群机器人 @ 问答入口
- F2：产品知识库向量化（支持 .md / .txt / .pdf）
- F3：混合检索（BM25 + 向量 + RRF）+ Reranker 重排
- F4：FABE 话术格式化输出
- F5：招标文件 PDF 上传 → 7 章响应初稿
- F6：知识库增量更新 API

**❌ 本期不做**：
- 语音输入 / 语音输出
- 多轮上下文记忆
- 外部 CRM 自动同步
- Docker/K8s 集群化部署
- Web 前端管理后台（MVP 用 API + 飞书即可）

---

## 6. 验收标准（Definition of Done）

1. 在飞书创建机器人，销售群里 @它 能收到自动回复
2. 产品白皮书 50 页 → 向量化索引成功，返回 4000 维向量
3. 测试集 20 个真实销售问题 → 至少 16 个返回的参考片段里有正确答案
4. 上传招标文件 PDF → 30 秒内返回 7 章结构化文档
5. 单机部署：M1 Mac 8GB 内存 + 本地运行，峰值内存 < 1GB
