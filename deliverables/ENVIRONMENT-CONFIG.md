# 软硬件环境配置清单

**目标**：M1 Mac 8GB 内存 + 系统盘 10GB 可用空间 + 0 元预算
**状态**：已在 FDE 本地验证通过 · 可直接部署

---

## 1. 硬件要求

| 组件 | 最低配置 | 推荐配置 | 说明 |
|------|----------|----------|------|
| **CPU** | Apple M1 | Apple M1 / M2 / M3 | M 系列统一架构，PyTorch MPS 加速推理 |
| **内存** | 8 GB | 16 GB | 8GB 跑 bge-small-zh 完全够用；16GB 可升级 bge-reranker |
| **存储** | 10 GB 可用 | 20 GB 可用 | Python venv + ChromaDB + 模型文件 < 1GB |
| **网络** | 能访问飞书 open.feishu.cn | — | 企业内网如果禁飞书 API，需要走代理 |

**⚠️ 不需要**：独立显卡、服务器、云主机、Docker Desktop（占 1GB+）

---

## 2. 软件清单（全部开源免费）

### 2.1 基础运行时

| 软件 | 版本 | 大小 | 下载 | 用途 | 费用 |
|------|------|------|------|------|------|
| **Python** | ≥ 3.10 | 自带 | 系统自带或 `brew install python@3.12` | 后端语言 | 免费 |
| **pip** | ≥ 24 | 自带 | Python 自带 | 包管理器 | 免费 |

### 2.2 核心依赖（pip 一键安装）

| 包 | 版本 | 作用 | 大小 | 费用 |
|----|------|------|------|------|
| **chromadb** | 1.5+ | 向量数据库（SQLite 后端，**不跑独立进程**） | 22 MB | Apache 2.0 |
| **sentence-transformers** | 3.3+ | Embedding 模型推理 | 80 MB | Apache 2.0 |
| **fastapi** | 0.115+ | HTTP API 服务框架 | 15 MB | MIT |
| **uvicorn** | 0.30+ | ASGI Server | 5 MB | BSD-3 |
| **python-multipart** | 0.0.12+ | 支持文件上传（招标文件） | 3 MB | Apache 2.0 |
| **requests** | 2.32+ | 调用飞书 Webhook | 3 MB | Apache 2.0 |
| **pypdf** | 5.0+ | 招标文件 PDF 解析 | 10 MB | BSD-3 |

**pip install 总大小 ≈ 140 MB**（加上传递依赖约 500 MB）

### 2.3 Embedding 模型（运行时自动下载）

| 模型 | 大小 | 精度 | 内存 | 说明 | 费用 |
|------|------|------|------|------|------|
| **BAAI/bge-small-zh-v1.5** | ~100 MB | MVP 够用 | ~300 MB | 中文专用，M1 友好，**首选** | MIT |
| BAAI/bge-m3 | 3.5 GB | 高精度多语言 | ~2 GB | MVP 跳过，后续升级用 | MIT |
| BAAI/bge-reranker-base | ~300 MB | 重排增强 | ~400 MB | MVP 跳过，后续加精排 | MIT |

### 2.4 飞书开放平台（配置项，无下载）

| 配置项 | 在哪里申请 | 费用 |
|--------|-----------|------|
| **企业自建机器人** | [open.feishu.cn](https://open.feishu.cn) → 创建应用 → 添加机器人能力 | 免费 |
| **App ID / App Secret** | 应用「凭证与基础信息」页面 | 免费 |
| **Webhook 地址** | 应用「事件订阅」页面，填入 FastAPI 的 URL | 免费 |

## 3. 软件 vs 流程对应关系

```

               │ HTTP POST (Webhook)
               ▼

               │ 调用
               ▼

│  SentenceTransformers（Embedding 推理）                   │

│  - 1024 维向量                                            │
│                                                          │

│                                                          │
│  依赖：chromadb                                           │
└──────────────────────────────────────────────────────────┘
```
