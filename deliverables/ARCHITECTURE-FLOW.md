# 架构与流程图

## 1. 系统整体架构

```
                           ┌─────────────┐
                           │   销售团队   │
                           │  @机器人提问  │
                           └──────┬──────┘
                                  │ 飞书 Webhook
                                  ▼
 ┌───────────────────────────────────────────────────────────────┐
 │                      FastAPI 后端                              │
 │                                                               │
 │  /query  ──→ 1. 解析问题                                       │
 │              2. BM25 + 向量混合检索 ──→ ChromaDB                │
 │              3. bge-reranker 精排                              │
 │              4. FABE 格式化                                   │
 │              5. 调 LLM 生成最终话术                            │
 │                                                               │
 │  /upload ──→ 1. pypdf 提取 PDF 文本                           │
 │              2. 7 章结构化拆分                                │
 │              3. 逐章向量化入库                                │
 │              4. 召回相似中标案例                               │
 │              5. 生成技术响应初稿                               │
 │                                                               │
 │  /ingest ──→ 上传新文档 → 切片 → 向量化 → ChromaDB upsert      │
 └──────────┬──────────────────────┬────────────────────────────┘
            │                      │
            ▼                      ▼
  ┌───────────────────┐   ┌─────────────────────────┐
  │  ChromaDB          │   │  SentenceTransformer     │
  │  (SQLite 后端)     │   │  (bge-small-zh-v1.5)    │
  │  - collections     │   │  - embed()  → 1024 维   │
  │  - embeddings      │   │  - rerank()             │
  │  - metadata        │   │  - M1 MPS 加速          │
  └───────────────────┘   └─────────────────────────┘
                                    │
                                    │ 向量写入
                                    ▼
  ┌───────────────────────────────────────────────┐
  │  ./chroma_data/（本地文件，企业内网）           │
  │  - chroma.sqlite3    向量+元数据               │
  │  - 不涉及任何云存储 / 数据外发                   │
  └───────────────────────────────────────────────┘
```

## 4. 部署拓扑

```
[M1 Mac 本机]
├── /Users/you/live-ltc-rag/
│   ├── app.py              ← FastAPI 服务（唯一进程）
│   ├── chroma_data/        ← 向量库持久化
│   ├── knowledge/          ← 待入库的 .md/.txt/.pdf 原文
│   ├── requirements.txt
│   ├── .env                ← FEISHU_APP_ID / FEISHU_APP_SECRET
│   └── venv/               ← Python 虚拟环境
│
└── 端口 8001
       │
       │ 内网 8001 → 外网（Cloudflare Tunnel 或 frp）
       │ （MVP 用 trycloudflare.com 即可，0 元）
       ▼
飞书开放平台 → Webhook 地址填入 → 事件推送过来
```

**对外暴露**：
- **端口** 8001（仅 FastAPI 一个服务）
- **进程数** 1
- **运行方式** `uvicorn app:app --host 0.0.0.0 --port 8001`
- **开机自启** `brew services add uvicorn` 或 macOS launchd plist（MVP 手动启动即可）
